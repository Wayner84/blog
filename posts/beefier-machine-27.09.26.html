Beefier machine

27.09.26

I’ve been using my XPS 13 for about a year now. The CPU performance is still really good, but it only has 16 GB of RAM and no dedicated graphics card. Add a 4K display and the amount of software I tend to have running, and there are some things it just struggles with.

SolidWorks works fine most of the time, but the laptop gets seriously hot and loud once a model becomes complicated. With all of my usual software installed, the whole machine had started to bog down as well.

I tried running Linux on it and remoting into my desktop whenever I needed something heavier. That works completely fine when I have a good 5G connection. When I don’t, I’m stuck without the software I need. That’s no good at college when I need to run electrical simulation software, or on a customer’s site when I need PC-DMIS.

The XPS is a lovely size and it has been a great machine. It just isn’t quite what I need anymore.

Turning the Legion Go into a laptop

That’s when I found this Legion Go keyboard case design on Etsy, made by MysteriousAlarm987. It takes the Legion Go I already own and turns it into a very portable little laptop.

The case does require a specific Lenovo Bluetooth keyboard, but it’s a good keyboard. It can remember three Bluetooth connections, so I can use the same one with my PC, phone and the Legion Go. Laptop might be a generous name for the finished thing. Phattop, maybe?

The Legion Go is not small. It’s thick already, and adding the keyboard makes the complete device fairly chunky. It is still smaller than a typical laptop in width and height though, which makes it easy to throw in my bag.

Much more useful performance

The big advantage is the performance. The Legion Go doesn’t have a dedicated GPU, but its AMD Ryzen Z1 Extreme is an APU with integrated Radeon graphics designed for handheld gaming. From my own testing it can handle some pretty intense games, so it has plenty to work with for the software I use away from my desk.

Its display is 2560 × 1600 at up to 144 Hz. Everything feels buttery smooth, and there’s enough resolution for the applications I need. The interface can be a bit small, but that’s how I prefer it anyway.

Two weeks in

I’ve been using it like this for about two weeks now. I’ve taken it to college, installed all the software I need and set up my network shares so I can access my files remotely. Unlike remoting into my desktop, the actual applications are installed locally, so a bad mobile connection doesn’t leave me without the tools I need.

Storage is decent too. It has a 512 GB SSD and a 512 GB microSD card, so I can keep all of my work software on it and still have room for a good few games.

At this point it’s becoming my new laptop. I’ll keep the XPS around for the time being, but I’m considering downgrading it to a spare 256 GB SSD and putting its 512 GB drive into the Debian server.

I may change my mind on that. The server stores its actual files on the other hard drives rather than the NVMe drive, so the extra space there might be wasted. A decent spare 512 GB SSD is likely to be more useful in another project, and I’m sure another project will appear sooner or later.
